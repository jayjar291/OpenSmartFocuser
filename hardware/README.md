# Hardware

This folder contains the mechanical and electronic source files for the OpenSmartFocuser build.

## Folder Structure

```text
hardware/
├── cad/   # Mechanical CAD models, drawings, and exports
└── pcb/   # KiCad PCB source files and fabrication assets
```

## What Belongs Here

- Mechanical source files used to model the focuser assembly.
- PCB design files used to route, review, and manufacture the controller board.
- Exported files that are still part of the design source, such as STEP, DXF, and fabrication references.

## Related Files

- See [CAD files](cad/README.md) for the mechanical design folder.
- See [PCB files](pcb/README.md) for the KiCad project and fabrication workflow.
